# CalverIS Language Support for Acode

Plugin editor untuk file `.cvis`.

## Fitur v0.2.0

- Mengenali ekstensi `.cvis`.
- Syntax highlighting dasar untuk kata kunci CalverIS, teks, angka, fungsi bawaan, dan label blok polyglot.
- Autocomplete untuk sintaks inti dan nama blok bahasa.
- Mengenali `variabel` dan alias singkat `var` sebagai deklarasi variabel.
- Mengenali `konst`, `kembali`, `bukan`, dan kata kunci CalverIS terbaru.

Plugin ini **tidak** menjalankan file `.cvis`. Untuk menjalankan program, gunakan CalverIS Core dan Python runtime yang sesuai.

## Instalasi

1. Unduh ZIP plugin.
2. Acode → Settings → Plugins → `+` → LOCAL.
3. Pilih ZIP plugin.
4. Buka file `.cvis`.
